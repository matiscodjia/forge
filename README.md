# Forge

A personal training system for becoming an interview-ready ML engineer.

- **Today** — six daily blocks, streak, focus timer
- **Arena** — 15 coding patterns, real Python (Pyodide) against hidden tests, timed mocks
- **Diagnostic** — coding mock + ML, math and PyTorch/systems parts with key-point grading
- **Skills, Scorecard, Pipeline** — levels, weekly numbers, applications board

All data stays in your browser (localStorage). Use **Export** for backups.

Static site: open `index.html` through any web server, or GitHub Pages.
